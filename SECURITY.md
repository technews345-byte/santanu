# Security Policy

## Supported versions

Only the latest code on the `main` branch is supported. This covers:

| Part | Supported |
| ---- | --------- |
| Bowl Mania website and admin panel (`bowl-mania-site/`), latest on `main` | ✅ |
| Bowl Mania Rider Android app (`rider-app/`), latest release | ✅ |
| Older releases and branches | ❌ |

## Reporting a vulnerability

**Please do not report security problems in public issues.**

Report them privately through GitHub instead:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it and the possible impact.

**What to expect**

- You'll get a reply within **3 working days**.
- I'll keep you updated at least once a week until the problem is resolved.
- If the report is accepted, the fix is released as soon as possible and you'll be credited, if you wish.
- If it's declined, I'll explain why.

Thank you for helping keep Bowl Mania and its customers safe.

— R&R Dev
